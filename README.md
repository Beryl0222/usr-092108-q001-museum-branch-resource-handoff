# 博物馆分馆资源接力

大同市博物馆总馆公共教育部的跨馆资源接力服务：为馆藏真品、可移动复制品、
数字内容、展陈版本、场地环境、讲师资历、课程材料、团体预约、散客候补、
运输交接与活动反馈建立稳定身份，并沿用统一事件信封同步九座分馆与
每年 150+ 场社教活动。

带队老师预约北魏服饰复原课时看到的内容——哪座分馆、教具是否到、
无障碍名额余多少、临时闭馆后的替代场次——全部可由事件流重放还原，
且与现场一致；总馆随时识别资源正在途中、待检查或可再次使用。

## 目录

- `src/catalog.py`：聚合身份、事件目录、payload 必填项（单一事实源）。
- `src/validator.py`：事件信封基础校验 + 事件/聚合配对与离线补报校验。
- `src/replay.py`：事件重放与只读投影（场次还原、预约页、总馆台账、资源时间线、时点重放）。
- `src/policies.py`：三类资源借调条件、异常影响范围、保障容量、讲师与运力争用。
- `contracts/domain.schema.json`：由 catalog 生成的 JSON Schema（勿手改）。
- `data/sample.json`：早期最小样例（保持兼容）。
- `data/scenario_northern_wei.json`：北魏服饰复原课完整联调事件流（106 条）。
- `tools/`：`generate_schema.py`、`build_scenario.py`。
- `docs/domain-model.md`：领域模型与规则详述。
- `tests/`：契约、策略、端到端场景验收（37 项）。

## 关键规则

1. **事件只追加**：标识、发生时间、版本不原地改写；更正产生后继事件。
2. **三类资源三套借调条件**：真品要温湿度+保险押运，复制品要车辆装载，
   数字内容要看授权范围与有效期。
3. **异常只重排受影响资源**：运输迟延只动迟到单上的资源；温湿度异常只撤真品；
   场馆停用只影响时间窗内场次。
4. **保障名额独立记账**：儿童团体池与无障碍池不被普通预约占用，候补同池 FIFO 补位。
5. **离线补报只认一次**：开始/完成/归还携带 `dedupe_key`，重复投递按业务事实去重。
6. **讲解定版不可变**：内容更新发布新版本，旧场次保留当时锁定的解释快照。

## 本地检查

```bash
python3 -m tools.build_scenario      # 重新生成样例事件流
python3 -m tools.generate_schema     # 重新生成 JSON Schema
python3 -m unittest discover -s tests
```

## 领域边界

涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段；
散客候补与反馈中的个人信息仅保留预约/联系所必需的最小集合。
