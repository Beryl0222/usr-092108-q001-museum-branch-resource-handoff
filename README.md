# 博物馆分馆资源接力

本仓库保存大同市博物馆总馆公共教育部"跨馆资源接力服务"的领域资料、事件契约与可执行验收，供业务团队在统一语义上继续建设。

## 场景

九座分馆、每年 150 余场社教活动共用同一批复制教具、讲师与运力。带队老师预约"北魏服饰复原课"时最关心四件事：**在哪座分馆、教具是否已到、无障碍名额还有多少、临时闭馆后接到哪场替代场次**。服务以事件溯源方式回答这些问题，并保证：

- 真品、复制品、数字内容各按条件借调（真品受温湿度约束，复制品实体周转，数字内容授权并发不占运力）；
- 温湿度异常、运输迟延、场馆停用**只重排受影响资源**，其余预约不动；
- 儿童团体与行动不便者的**保障名额不被普通预约或平均分配吞掉**，场次迁移时随预约平移；
- 分馆离线补报的开始、完成、归还**只认一次**（幂等键）；
- 讲解/展陈/材料更新不影响旧场次——每场活动固化当时版本，历史可还原；
- 从任一场次可还原物品、人员、场地、异常交接、内容版本与反馈。

## 仓库内容

- `docs/domain-model.md`：领域模型（稳定身份、借调条件、异常局部重排、保障名额、幂等补报、版本固化、资源状态、验收口径）。
- `contracts/domain.schema.json`：事件信封 JSON Schema。沿用 v0.1 必填字段，新增 14 类聚合、41 类事件，以及可选的 `idempotency_key` / `correlation_id` / `caused_by_event_id` / `payload`。
- `data/sample.json`：**北魏服饰复原课完整接力事件流**（111 条正式事件 + 2 条应被丢弃的重复投递）。由 `tools/build_sample.py` 生成，覆盖：在册封档、约课与候补、温湿度撤回真品、运输迟延急运顶替、临时闭馆整体迁移平城分馆、保障名额平移、离线补报、归还查验（一件破损隔离后修复）、反馈、讲解 v2 发布后旧场次仍指向 v1。
- `src/validator.py`：信封校验、事件流一致性（唯一标识、聚合版本递增、因果引用）、幂等去重 `deduplicate()`。
- `src/projection.py`：事件投影——
  - `resource_status()` / `resources_by_state()`：可预约 / 已预约 / 途中（含迟延标注）/ 待检查 / 使用中 / 可再次使用；
  - `session_view()`：还原一场活动的物品、人员、场地、运单、预约、候补、异常因果链、离线补报、固化内容与反馈；
  - `booking_page()`：预约页四问（开场时刻切片，与现场一致）；
  - `anomaly_chain()`：根因事件 → 全部重排动作；
  - `check_invariants()`：保障名额、真品环境条件、运力争用、讲师资质与撞档、固化版本存在性、替代场次闭环、开课时教具就位。
- `tests/`：24 项测试，含样例正向验收与合成违规反例（超用名额、普通席侵占保障、告警中调真品、运单重叠、无资质讲师、替代场容量不足）。

## 事件信封

```json
{
  "event_id": "261016-062",
  "event_type": "VENUE_TAKEN_OUT_OF_SERVICE",
  "aggregate_type": "venue",
  "aggregate_id": "V-MT",
  "occurred_at": "2026-10-16T18:00:00+08:00",
  "version": 5,
  "summary": "明堂分馆供暖管道故障，10月17日临时闭馆",
  "correlation_id": "RELAY-20261017-BEIWEI",
  "payload": { "venue_id": "V-MT", "reason": "heating_pipe_failure" }
}
```

事件一经接收不可原地改写；业务更正只产生后继事件。异常重排事件以 `caused_by_event_id` 回指根因；离线补报携带 `idempotency_key`，同键只生效一次。

## 本地检查

```bash
python3 tools/build_sample.py           # 重新生成样例事件流
python3 -m unittest discover -s tests   # 全部验收测试
```

`jsonschema` 为可选依赖；安装后测试会额外用 JSON Schema 深度校验每条事件，未安装时自动跳过。
